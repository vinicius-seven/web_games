Pontes

Ligue as ilhas do arquipélago com pontes de madeira. O número de cada ilha diz quantas pontes saem dela.

Mapa do dia

Escolha o mar

Regras

  1. Cada ilha recebe exatamente o número de pontes escrito nela.
  2. Pontes só em linha reta (horizontal ou vertical), com no máximo 2 entre as mesmas ilhas.
  3. Pontes não se cruzam.
  4. No fim, todas as ilhas precisam estar ligadas num só caminho.

Arraste de uma ilha na direção da vizinha (ou toque no mar entre as duas) para pôr uma ponte. Repita para a segunda; a terceira vez remove. Cada mapa tem uma única solução e fecha só com raciocínio.
