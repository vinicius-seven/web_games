Escada

Suba de uma palavra a outra trocando uma letra por vez. Todo degrau precisa ser uma palavra de verdade.

Como jogar
  • Escreva uma palavra que mude só uma letra da anterior, no mesmo lugar (sem mudar a ordem nem o tamanho).
  • Continue até chegar à palavra de baixo. Acentos não importam na hora de digitar.
  • Cada escada mostra o mínimo de degraus possível. Chegar no mínimo, sem dica, vale 3 estrelas.
  • Letras que já estão no lugar certo da palavra final ficam verdes. Toque num degrau para voltar a ele.
  • A escada do dia é a mesma para todo mundo; a livre sorteia uma nova sempre que você quiser.
